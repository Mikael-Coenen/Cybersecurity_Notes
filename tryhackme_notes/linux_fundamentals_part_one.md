- Linux is very lightweight
- Linux is an umbrella term for OS's based on UNIX
- Ubuntu for example is a distribution of linux (a variant)

- Learned commands:
- Echo: outputs text you provide
- whoami: tells you what user your currently logged in as
- ls: lists directories/folders available
- cd: change directory
- cat: "concatenate" but really means output contents of a file
- pwd: print working directory
- find -name: finds the location of a certain file
    - find -name *.something: allows you to find files of a certain extension
- grep: searchs for a certain specified text in a text file

- Learned shell operators:
    - &: allows you to run commands in the background
    - &&: allows you to make a list of commands to run (not simultaneously, rather one after the other)
    - >: Output redirector, the output of a command is redirected elsewhere and replaces the content of the place the output is sent to
    - >>: Same as ">" but allows you to append output rather than having the output replace whatever was already in that location

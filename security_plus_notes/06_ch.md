# Software Assurance Best Practices
## The Software Development Life Cycle
- Software Development Life Cycle (SDLC): describes steps in a model for software development throughout its life
- Secure SDLC practices aim to integrate security into the development process
## Software Development Phases
- Planning: investigations into whether the effort should occur
- Requirements: customer input is sought to determine desired functionality
- Design: design for various elements
- Coding: actual coding of application
- Testing: testing with ppl outside of development team
- Training and Transition: ensure end users are trained on the software
- Operations and Maintenance: patching, updating, minor modifications
- Decommissioning: shutting down old products, systems that need to be disposed of
## DevSecOps and DevOps
- DevOps: combines software development and IT operations with goal of optimizing SDLC
- DevSecOps: describes security as part of DevOps model 
## Continous Integrationand Continous Deployment
- Continous integration: consistently checks code into a shared repository
- Continous deployment: rolls out changes into production automatically as soon as they have been tested
- Using CI and CD requires continous validation and automated security testing

# Designing and Coding for Security
## Secure Coding Practices
- OWASP: resource for secure coding practices
- Top OWASP control: define security requirements, leverage security frameworks, secure database access, encode and escape data, validate all inputs, implement digital identity, enforce access controls, protect data everywhere, implement security logging, handle all errors
## API Security
- Application Programming Interface (APIs): interface between client and server or app and os that define how the client should ask for info from the server and how the server will respond
- API security relies on authentication, authorization, and proper data scoping to ensure too much data isnt released
